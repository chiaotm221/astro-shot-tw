# Photo Capture Checklist

The following Traditional Chinese product copy is intended for the future photo
import flow and should appear before the user selects an image.

## Full Traditional Chinese Product Copy

### 拍攝前請先確認

為了讓模擬星空與實景相片更準確地對齊，建議使用手機或相機的原始相片，並保留拍攝時間、GPS 與焦距等資訊。

拍攝時請注意：

- 橫向或直向都可以，但請選定一種方向後完成拍攝，不要在拍攝後任意旋轉或大幅裁切。
- 若想呈現寬廣地景、銀河或長星軌，建議使用橫向拍攝。
- 若想呈現高聳建築、山峰、樹木或較多天空，建議使用直向拍攝。
- 開啟手機相機的「位置資訊」或 GPS 紀錄功能，並允許相機在拍照時儲存位置。
- 確認裝置的日期、時間與時區正確，避免星空位置產生明顯誤差。
- 拍攝前記錄鏡頭面向的方向，例如北、東北、東，或使用羅盤記下約略角度。
- 盡量記錄相機是水平、向上仰拍或向下俯拍；若畫面有傾斜，也請記下大約角度。
- 保留原始焦距資訊。若使用手機的 0.5×、1×、2× 等鏡頭，請記住使用的倍率。
- 畫面中若能保留清楚的地平線、山稜、建築垂直線或其他方向參考，會更容易校正。
- 避免先透過通訊軟體或社群平台傳送相片，這些服務可能會移除 EXIF、GPS、時間與焦距資訊。
- 優先匯入手機或相機直接產生的原始檔，不要使用螢幕截圖。

### 隱私提醒

相片的 EXIF 可能包含精確 GPS 位置。程式應先在裝置上讀取資料並顯示給你確認；未經同意，不應上傳相片或座標。

### 如果相片沒有 GPS 或方向資料

仍然可以使用，但需要手動提供：

- 拍攝地點或經緯度
- 拍攝日期與時間
- 時區
- 鏡頭面向方向
- 大約仰角與畫面傾斜
- 使用的鏡頭倍率或焦距

提供的資訊越完整，模擬星空、銀河方向與星軌位置就越接近實際拍攝畫面。

## Compact Traditional Chinese Product Copy

```text
選取相片前，建議使用未裁切、未經通訊軟體壓縮的原始檔，並在拍照時開啟 GPS 位置紀錄。請確認裝置日期、時間與時區正確，記下拍攝方向、鏡頭倍率，以及相機大約是水平或向上仰拍。橫向適合寬廣地景與銀河，直向適合高聳地景與較多天空。相片若缺少 GPS、方向或焦距，之後仍可手動補充。
```
