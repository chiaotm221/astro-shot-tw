# V7.0 — Validated Solar-System Ephemerides

## Status

Planned after V6.1.

## Objective

Replace deferred or low-precision solar-system behavior with one validated,
documented calculation layer suitable for observing recommendations.

## Scope

- Calculate apparent positions for the Moon, Mercury, Venus, Mars, Jupiter,
  and Saturn for the supported date range.
- Produce altitude, azimuth, rise, transit, and set events from shared pure
  functions.
- Use those results consistently in Tonight's Sky, object search, object
  information, and camera planning.
- Include Moon and visible planets in recommendations only when their computed
  state passes validation and visibility rules.
- Document the reference source, comparison dates, locations, tolerance, time
  scale, refraction assumptions, and known limitations.

## Validation Plan

- Compare a matrix of dates, Taiwan locations, horizon events, and meridian
  events against an authoritative published ephemeris or maintained reference
  implementation.
- Test dates around leap years, UTC/local-day boundaries, conjunctions, and
  objects near the horizon.
- Keep deterministic fixtures in the repository with source and retrieval date.
- Define separate tolerances for angular position and event time before
  implementation is considered complete.

## Constraints

- Do not duplicate astronomical formulas in UI components.
- Do not silently mix geometric and apparent coordinates.
- Avoid a large dependency unless its accuracy, license, bundle size, and
  offline behavior are justified and documented.
- Preserve fully offline calculations after the application assets are cached.

## Acceptance Criteria

- Every supported body has validated position and event calculations across the
  documented date range.
- Recommendation, search, information-card, and camera views agree for the same
  place and time.
- Accuracy limits and approximation notices are visible where relevant.
- Unit and browser tests cover representative events and date boundaries.

## Deferred

- Telescope control, plate solving, and physical camera control.
- Satellites, comets, asteroids, and user-supplied orbital elements.
- Professional-grade astrometry beyond the documented planning tolerance.
