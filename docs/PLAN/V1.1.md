# V1.1 Plan — Taiwan Observing Sites

## Status

Implemented. Full local build and browser verification remain required in an
environment with Node.js and installed dependencies.

## Goal

Allow users to select a Taiwan observing site and immediately update the sky
projection from that site's latitude and longitude.

## Scope

- Taipei, Taichung, Tainan, Kaohsiung, Alishan, Hehuanshan, and Kenting.
- A controlled observing-site selector with Traditional Chinese labels.
- Visible site, region, latitude, and longitude information.
- Taipei as the deterministic default site.
- Client-side restoration through `astro-shot-observing-site`.
- Safe fallback for invalid site IDs or unavailable browser storage.
- Latitude integration through the existing settings flow.
- Longitude integration through the existing sidereal-time flow.

## Out of Scope

- Custom coordinates and browser geolocation.
- Weather, light pollution, and map data.
- Complete Traditional Chinese localization.
- Projection-formula changes.
- Animation-loop or renderer restructuring.

## Files

- `app/simulation/observing-sites.ts`
- `app/components/ObservingSiteSelector.tsx`
- `app/SkySimulator.tsx`
- `app/globals.css`

## Acceptance Criteria

- All seven sites are available.
- Switching sites requires no page reload.
- Latitude and longitude both affect the displayed sky.
- The selected site is visible in the interface.
- Refreshing restores the last valid selection.
- Invalid stored values fall back to Taipei.
- No hydration, Canvas, or WebGL errors occur.
- Camera, time, meteor, locale, and navigation behavior remain functional.
- Type checking, lint, tests, and production build pass.
- Static and Cloudflare build behavior remains compatible.

## Verification

```text
npx tsc --noEmit
npm run lint
npm test
npm run build
```

Perform browser verification at all seven sites and at desktop and mobile
viewport sizes.
