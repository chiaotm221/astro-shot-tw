# V3.2 Plan — Timeline and Overnight Playback

## Goal

Extend the existing left-side time menu into the single time-control surface for exploring an observing night.

## Phase 1 Delivery

- Display the simulated local date and time.
- Select a civil date while preserving the current time of day.
- Scrub through a 24-hour timeline in one-minute increments.
- Jump to sunset, the end of astronomical twilight, midnight, and the following sunrise.
- Keep the existing play/pause, speed slider, and 1×, 60×, 120×, 360×, and 720× presets.
- Synchronize sky orientation, Moon conditions, and Milky Way planning after every seek.

## Performance

The animation loop owns the mutable simulation clock. React samples it only while the time menu is open, at a fixed low frequency. Slider and event jumps update one ref; sidereal orientation is derived from that timestamp on the following frame.

## Accuracy

Sunrise and sunset use a −0.833-degree solar-altitude threshold. Astronomical dusk uses −18 degrees. Five-minute samples are interpolated, without terrain-specific horizon corrections.
