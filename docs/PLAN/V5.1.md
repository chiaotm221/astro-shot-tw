# V5.1 Plan — Photo Import, EXIF, and Privacy

## Goal

Let users inspect a local photograph and recover useful capture metadata without silently uploading or retaining the original image.

## Phase 1 Delivery

- Select a local image only after an explicit user action.
- Preview the file using a temporary object URL and revoke it when removed or unmounted.
- Parse JPEG APP1/TIFF EXIF locally with bounds checks.
- Read camera make/model, orientation, original capture time, focal length, 35 mm equivalent, GPS latitude/longitude, and altitude when present.
- Show missing fields as unavailable rather than inventing values.
- Enforce a 30 MB file-size limit and provide clear format limitations.

## Privacy

The original image and EXIF remain in the active browser tab. Phase 1 makes no upload request and does not persist the original file or preview. Only a future V5.4 external workflow may transmit an image, after separate explicit opt-in and provider disclosure.

## Follow-up

- V5.2 will expose editable confirmation fields and alignment controls.
- Add HEIC metadata only through a justified, browser-compatible parser with documented licensing and bundle impact.
- Preserve metadata provenance so user corrections never masquerade as original EXIF.
