# V2.3 Plan — Constellation Figures and Labels

## Goal

Make the simulated sky easier to recognize without obscuring the photographic presentation.

## Phase 1 Delivery

- Toggle constellation guide lines and localized names independently.
- Switch between a small primary set and the complete bundled set.
- Preprocess equatorial coordinates into vectors when the module loads.
- Project only the small prepared segment list in the render loop; no per-frame catalog matching is performed.
- Draw lines before stars so bright stars remain visually dominant.

## Data Note

Phase 1 contains simplified interpretive figures built from bright-star positions compatible with the bundled HYG-derived star catalog. The figures are recognition aids and are not official IAU constellation boundaries. HYG v4.1 is attributed in the application under CC BY-SA 4.0.

## Follow-up

- Expand the licensed figure set after visual and mobile-performance review.
- Add visual regression coverage at fixed sidereal times and locations.
- Consider separate official boundary data only with documented source and redistribution terms.
