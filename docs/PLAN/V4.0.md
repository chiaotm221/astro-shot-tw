# V4.0 Plan — Taiwan Observing Map

## Goal

Make the bundled Taiwan locations easier to compare and select without requiring a live map service.

## Phase 1 Delivery

- Show the seven bundled locations on a lightweight schematic Taiwan map.
- Filter locations by urban, highland, and coast categories.
- Select a map marker or list entry to update the simulator immediately.
- Show elevation plus qualitative light-pollution, horizon, access/parking, and caution notes.
- Preserve custom locations in the regular selector without inventing site metadata.

## Data and Safety

Coordinates and elevations reuse the bundled project dataset. Qualitative site notes are conservative static planning guidance, not live operational claims or precise Bortle measurements. The interface asks users to verify current road, park, parking, and weather notices before travel.

## Follow-up

- Add sourced static sites in east Taiwan and outlying islands.
- Record source dates for authoritative access and facility details.
- Keep live weather and road status in separate failure-tolerant integrations.
