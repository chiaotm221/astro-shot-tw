# V3.1 Plan — Milky Way Observing and Photography

## Goal

Turn the existing Milky Way rendering into a practical location- and time-aware planning aid for Taiwan observers.

## Phase 1 Delivery

- Calculate the Galactic Center's current azimuth and altitude.
- Estimate its next rise and set crossings.
- Estimate astronomical darkness using a solar-altitude threshold of −18 degrees.
- Search the following 24 simulated hours for periods where the core is above 10 degrees during astronomical night.
- Rank the window using core altitude and approximate moonlight interference from V3.0.
- Guide the sky view to the Galactic Center.

## Accuracy and Limitations

The Galactic Center uses the standard J2000 direction near Sagittarius A*. Solar, lunar, and crossing calculations are planning approximations. Weather, terrain, atmospheric refraction, local light pollution, and camera exposure are excluded and stated in the interface.

## Follow-up

- Add date selection and an overnight chart in V3.2.
- Validate seasonal windows against an authoritative astronomy package or ephemeris fixtures.
- Incorporate weather and light-pollution inputs only in their dedicated roadmap phases.
