# V1.3 Plan — Custom Observing Locations

## Status

Implemented. Full local build and browser verification remain required in an
environment with Node.js and installed dependencies.

## Goal

Allow users to enter or request a custom observing position while keeping all
location data on the device.

## Scope

- Accept a user-defined location name, latitude, and longitude.
- Validate latitude from -90 to 90 and longitude from -180 to 180.
- Request browser geolocation only after an explicit button press.
- Save valid custom locations in localStorage.
- Show recently saved custom locations in the existing selector.
- Restore a selected custom location after refresh.
- Provide clear Traditional Chinese validation and geolocation feedback.
- Reuse the existing latitude, longitude, and sidereal-time data flow.

## Privacy and Failure Behavior

- Do not request location permission automatically.
- Do not continuously watch the user's position.
- Do not transmit coordinates to a server.
- Treat localStorage and geolocation as optional browser capabilities.
- Fall back to Taipei if persisted data is invalid or unavailable.

## Expected Files

- `app/simulation/observing-sites.ts`
- `app/components/ObservingSiteSelector.tsx`
- `app/SkySimulator.tsx`
- `app/globals.css`
- `tests/rendered-html.test.mjs`

## Out of Scope

- Maps, reverse geocoding, and automatic place names.
- Remote accounts or synchronization.
- Background or continuous location tracking.
- Weather and light-pollution data.

## Acceptance Criteria

- Valid manual coordinates can be saved and selected without a page reload.
- Invalid coordinates cannot be saved and show a useful message.
- Geolocation is requested only from an explicit user action.
- Permission denial or unavailable geolocation does not break the simulator.
- Saved custom locations and the active selection survive refresh.
- Both latitude and longitude update the sky through the existing render flow.
- No hydration, Canvas, or WebGL errors occur.
- Type checking, lint, tests, production build, and browser checks pass.
