# V2.0 Plan — Tonight's Sky

## Status

Planned. Final astronomical scope and data sources require review before
implementation.

## Goal

Turn the simulator into an accessible observing assistant that recommends
objects visible from the selected location and time.

## Initial Object Set

- Moon
- Venus, Mars, Jupiter, and Saturn
- Sirius, Vega, Altair, Antares, Betelgeuse, and Polaris
- Pleiades and Orion Nebula

The final set depends on available, licensed data and validated calculations.

## Scope

- Calculate object visibility for the active site and simulation time.
- Classify objects as visible now, rising later, or already set.
- Show direction, altitude, brightness, and a recommended viewing method.
- Present approximate values and calculation limitations clearly.
- Navigate the existing sky view to a selected recommendation.
- Keep recommendation calculation outside the animation loop.

## Architecture

Expected modules:

```text
app/simulation/visibility.ts
app/simulation/celestial-object.ts
app/components/TonightRecommendations.tsx
app/hooks/useTonightRecommendations.ts
```

The celestial-object model should be reusable by V2.1 search and V2.2 object
information. UI modules must not duplicate astronomy formulas.

## Out of Scope

- Live weather and cloud forecasts.
- Telescope-control integration.
- AI-generated observing claims.
- Large external astronomy frameworks without a documented need.
- Per-frame recommendation recalculation.

## Data Requirements

For every new dataset, record its source, date, license, redistribution terms,
and attribution requirements. Distinguish calculated approximations from live
or authoritative observations.

## Acceptance Criteria

- Recommendations change correctly with site, date, and time.
- Objects below the horizon are not described as currently visible.
- Selecting a recommendation moves or guides the view to the object.
- Calculations do not reduce Canvas frame rate during normal interaction.
- Search and information features can reuse the chosen object model.
- Unit tests cover visibility boundaries and status classification.
- Fixed-input visual tests detect unexpected sky-direction changes.
- Type checking, lint, tests, production build, and browser verification pass.
