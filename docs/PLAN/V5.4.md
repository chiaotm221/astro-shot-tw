# V5.4 Plan — Plan Export and Optional External AI

## Phase 1 Delivery

- Export a versioned JSON photography plan containing site, simulation time, camera setup, original EXIF, confirmed capture values, preview settings, and limitations.
- Keep the original photo outside the JSON export.
- Compose and download a local PNG preview from the aligned photo and simulated sky canvas.
- Generate a provider-neutral AI handoff text file only after explicit acknowledgement.
- Make clear that no AI provider is configured or called and no photo is uploaded by the handoff action.

## Privacy Boundary

Local JSON and PNG export use browser Blob URLs and Canvas only. The optional handoff contains prompt text and plan metadata, not the image. Any future provider integration must separately disclose provider identity, transmitted content, retention implications, cost, and expected output before requesting upload consent.

## Export Schema

The JSON schema identifier is `astro-shot/photography-plan`, version 1. Original EXIF and confirmed corrections remain separate. Limitations travel with the plan so downstream tools cannot silently treat manual alignment or approximate astronomy as authoritative.

## Out of Scope

- Automatic upload to any AI provider.
- Provider API keys in client code.
- Guaranteed photorealistic, astrometric, or scientifically accurate composites.
