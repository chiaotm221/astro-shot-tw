# V2.2 Plan — Object Information

## Goal

Use one information-card model for search, recommendations, and canvas selection.

## Phase 1 Delivery

- Shows localized names, category, equatorial coordinates, current horizontal coordinates, magnitude, distance, constellation, and visibility when data is available.
- Updates location-dependent values while the card is open.
- Reuses one selected-object event and one card component across entry points.
- Clearly marks approximate calculated values and unavailable catalog fields.

Validated transit/set times and a broader sourced distance/description catalog remain follow-up work.
