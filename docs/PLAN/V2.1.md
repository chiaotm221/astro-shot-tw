# V2.1 Plan — Object Search

## Goal

Let users find catalogued celestial objects by Chinese or English name and smoothly guide the sky view to the selected result.

## Scope

- Build one reusable, pre-normalized search index outside the animation loop.
- Search localized names, common aliases, and catalogue identifiers.
- Classify stars, planets, constellations, and deep-sky objects in the shared model.
- Smoothly move the view and briefly identify the selected target.
- Keep the catalog small and curated until a licensed larger dataset is selected.

Planet search entries are deferred until their coordinates use validated time-dependent ephemerides; fixed coordinates must not be presented as current planet positions.

## Acceptance Criteria

- Chinese and English searches are case-insensitive and tolerate spaces and hyphens.
- Results expose their object category and alternate localized name.
- Selecting a result smoothly guides the view and displays a temporary target marker.
- Search does no work in the canvas animation loop.
- Type checking, lint, tests, production build, and browser verification pass.
