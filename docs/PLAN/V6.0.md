# V6.0 — Installable PWA and Offline Foundation

## Status

Phase 1 is implemented. Production and base-path static exports pass automated
tests. Installed-app behavior, real browser disconnection, service-worker
updates, and storage-pressure behavior still require manual or browser-level
verification.

## Objective

Keep AstroShot's core planning and sky-simulation features available when an
observing location has an unstable or unavailable network connection.

## Implemented Scope

- Web app manifest with standalone display metadata and install icons.
- Apple web-app metadata for supported mobile browsers.
- Service-worker registration that respects the configured deployment base
  path.
- Precache attempts for the application entry point, star catalog, Milky Way
  texture, manifest, and primary icons.
- Runtime caching for successful same-origin GET requests.
- Network-first navigation with a cached application-shell fallback.
- Bundled observing sites and browser-local astronomy calculations that do not
  require a server request.
- A visible offline indicator.
- Cached weather fallback with an explicit cached-data label and data age.

## Non-Goals

- Offline refreshes of current weather or other live external data.
- Background synchronization or push notifications.
- Accounts, cloud synchronization, or remote storage of observing locations.
- A complex service-worker framework or new runtime dependency.

## Acceptance Evidence

- The production static export succeeds.
- A static export using `/astro-shot` as its base path succeeds.
- The exported HTML references the base-path-aware manifest.
- The manifest start URL, scope, and icon URLs respect the base path.
- The exported service worker contains navigation fallback and star-catalog
  caching logic.
- Existing astronomy, rendering, localization, and export tests remain green.

## Remaining Verification

- Install and launch the app in standalone mode on current Chromium and iOS
  Safari versions.
- Load the app once, disconnect the network, reload it, and confirm that the
  sky, bundled sites, search, moon, Milky Way, and photography tools work.
- Confirm cached weather is never presented as live data.
- Confirm a failed or partial precache does not prevent service-worker
  activation.
- Confirm recovery after storage eviction and after a new deployment replaces
  the previous cache version.

## Exit Criteria

V6.0 is complete when the remaining browser checks are recorded without a
critical offline regression. Cache management and update user experience belong
to V6.1.
