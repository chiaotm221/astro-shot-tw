# V6.2 — Field Plan Export and Sharing

## Status

Phase 1 implemented. Static export and deterministic serialization tests are
complete. Mobile share-sheet and browser print-dialog checks remain pending.

## Objective

Turn the existing local JSON and PNG exports into a field-friendly observing
and photography plan that can be printed, saved as PDF, or intentionally shared
without uploading the original photograph.

## Implemented Scope

- Preserve the versioned `astro-shot/photography-plan` JSON format.
- Add planning summaries for Moon illumination, cached weather, and recommended
  camera equipment.
- Generate a localized, mobile-readable print document that browsers can print
  or save as PDF with system fonts.
- Use the Web Share API when available and copy a link as the fallback.
- Encode shared plans in the URL fragment so the payload is not included in a
  normal HTTP request.
- Remove original EXIF and confirmed capture data from the share payload.
- Detect shared-plan fragments on arrival and show a localized summary with a
  JSON download action without contacting a server.
- Keep planned site, time, camera, Moon, and cached-weather summaries visible in
  the link and explain that privacy boundary before sharing.
- Escape user-controlled values in printable HTML.

## Constraints

- Do not upload the original photograph or plan data.
- Do not add a large PDF dependency solely for browser export.
- Keep JSON, print/PDF, and shared-link values derived from one plan model.
- Treat Web Share, clipboard, pop-up, and print support as optional browser
  capabilities with clear failure feedback.

## Acceptance Criteria

- JSON export remains backward compatible and excludes image payloads.
- Print output includes site, date, coordinates, elevation, camera settings,
  Moon illumination, cached-weather summary, equipment, and limitations.
- A supported mobile browser can open its native share sheet.
- A browser without Web Share can copy the privacy-reduced link.
- Shared Unicode plan data round-trips without EXIF or confirmed capture data.
- Opening a shared link presents its site, time, camera, and Moon summary.
- User-provided site names cannot inject markup into the print document.

## Remaining Browser Verification

- Save English and Traditional Chinese plans as PDF on desktop and mobile.
- Exercise Web Share on Android and iOS and clipboard fallback on desktop.
- Confirm pop-up blocking and denied clipboard permission produce useful
  localized feedback.
- Confirm long but valid custom-site names remain readable in print layout.

## Deferred

- Server-hosted short links and link expiration.
- Cloud plan storage or cross-device synchronization.
- Embedded original photographs in PDF files.
- Cryptographic encryption of shared fragments.
