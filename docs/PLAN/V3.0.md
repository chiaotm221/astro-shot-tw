# V3.0 Plan — Moon Phase and Moonlight

## Goal

Provide the Moon information most useful for practical observing and night-sky photography.

## Phase 1 Delivery

- Calculate approximate lunar phase, illumination, age, equatorial position, azimuth, and altitude locally.
- Estimate the next moonrise and moonset by sampled horizon crossings.
- Classify moonlight impact using illumination and whether the Moon is above the horizon.
- Preview phase and illumination for the following four simulated days.
- Drive all values from simulation time, including pause and acceleration.

## Accuracy

The implementation uses compact low-precision solar and lunar formulae suitable for planning and visualization. Rise/set values use ten-minute samples with interpolation. Results omit atmospheric refraction, parallax, terrain, and authoritative ephemeris corrections and are labeled approximate in the interface.

## Follow-up

- Validate fixed-date calculations against an authoritative ephemeris dataset.
- Draw the Moon in the sky canvas with correct phase orientation.
- Add civil-date selection as part of the V3.2 timeline.
